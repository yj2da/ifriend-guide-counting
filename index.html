🔥 Firebase 실시간 동기화 설정

와이파이가 달라도, LTE/5G 어디서든 모든 폰에서 점수를 실시간으로 함께 보려면 Firebase Realtime Database URL을 입력하세요.

💡 1분 무료 설정 방법:
1. Firebase 콘솔에서 프로젝트 생성 (무료)
2. 빌드 > Realtime Database 만들기 클릭
3. 규칙(Rules) 탭에서 ".read": true, ".write": true 설정
4. 상단의 Database URL을 복사하여 위 입력란에 붙여넣기!
