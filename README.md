# 아이프렌드 27기 오프닝 세레모니 점수 체크 웹앱 (i-FRIEND Score System)

아이프렌드(i-FRIEND) 27기 오프닝 세레모니 현장에서 임원진(예진, 민혁)이 조별 점수를 실시간으로 입력·집계하고, 프로젝터 스크린에 진행 상황 및 최종 결과를 발표할 수 있는 반응형 실시간 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **임원별 담당 조 점수 분담 입력**:
   - **예진 임원**: 1조 · 2조 · 3조
   - **민혁 임원**: 4조 · 5조 · 6조
   - 각자의 스마트폰/노트북으로 동시 접속하여 실시간 분담 입력 지원

2. **종목별 측정 및 자동 배점 엔진**:
   - **🎯 빙고게임**: 점수 직접 입력 (기본 점수)
   - **🗼 신문지탑**: **cm(높이)** 입력 → **높을수록 1등** (🥇 1등 15점, 🥈 2등 10점, 🥉 3등 5점)
   - **⚾ 신문지공**: **cm(둘레/크기)** 입력 → **작을수록 1등** (🥇 1등 15점, 🥈 2등 10점, 🥉 3등 5점)
   - **⭐ 개별점수**: 팀원별 이름과 보너스 점수를 자유롭게 등록 (`+ 인원 추가`)하여 개인별 랭킹 산출
   - **미기입 자동 처리**: 입력하지 않은 필드는 자동으로 0점으로 안전하게 계산

3. **📊 실시간 진행 상황 보기 (`view-progress`)**:
   - 게임별 순위 탭 필터링 (`전체`, `빙고게임`, `신문지탑`, `신문지공`, `개별점수`)
   - 신문지탑/신문지공의 cm 기록 및 획득 점수 실시간 랭킹 확인
   - 개별점수 개인별 순위 (1위~n위) 확인

4. **🏆 최종 결과 발표 및 시상 (`view-final`)**:
   - 3대 게임(빙고 + 신문지탑 + 신문지공) 합산 기준 전체 1~6위 순위 발표
   - 1위, 2위, 3위 단정하고 품격 있는 하이라이트 카드 및 화려한 축하 폭죽(Confetti) 효과
   - 전체 조별 점수 합산 상세표 제공

5. **⚡ 실시간 데이터 동기화 (Server-Sent Events)**:
   - 한 임원이 폰에서 점수를 입력하고 저장하면, 프로젝터 화면 및 다른 임원의 기기에 **새로고침 없이 실시간 자동 동기화**
   - 서버의 `scores_data.json` 파일에 자동 보존되어 서버 재시작 후에도 안전하게 유지

## 🚀 로컬 실행 방법

### 요구 사항
- Node.js (v16 이상 권장)

### 실행 명령어
```bash
# 1. 저장소 클론
git clone https://github.com/yj2da/ifriend-guide-counting.git
cd ifriend-guide-counting

# 2. 서버 실행 (별도 npm 패키지 설치 필요 없음!)
npm start
# 또는
node server.js
```

### 접속 주소
- **PC 브라우저**: `http://localhost:3000`
- **동일 Wi-Fi 내 스마트폰/태블릿**: `http://[호스트PC_IP주소]:3000`
